# Índice de Discovery de Producto — NOVA ✨

Este directorio contiene las propuestas de oportunidad de producto investigadas y diseñadas por **NOVA ✨**, el agente visionario de producto de LucidFence.

Todas las propuestas en este índice representan oportunidades evaluadas minuciosamente bajo los principios de innovación, viabilidad técnica, diferenciación competitiva y alineación con la filosofía local-first de LucidFence 2.0.

## Estado del Ciclo de Vida de Propuestas

- **EXPLORE**: Propuestas e hipótesis bajo investigación o diseño conceptual (no aprobadas aún para implementación).
- **DISCOVERY**: Propuestas validadas para experimentación técnica o pruebas con usuarios.
- **PARKED**: Oportunidades pausadas o sustituidas por enfoques superiores.

## Principios de Diseño de Oportunidades

1. **Local-first & Cero Telemetría**: Ninguna propuesta debe requerir la exfiltración de coordenadas ni datos sensibles a nubes de terceros.
2. **Complemento del UEM, Nunca un UEM**: Apalancar las capacidades de Applivery, Intune, Jamf, Fleet y Workspace ONE.
3. **Paso Inicial Pequeño (Thin Slice)**: Cada oportunidad debe definir un primer experimento o versión mínima útil de extremo a extremo.
4. **Verificación Rigurosa**: Toda propuesta debe cumplir con el estándar mínimo de 20 secciones de oportunidad antes de entrar en discovery.
