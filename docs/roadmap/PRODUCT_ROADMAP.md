## Horizon: EXPLORE (NOVA Visionary Features)

The following proposals represent the visionary roadmap targeted for implementation by autonomous developer agents (Hermes):

### 2. [NOVA-001-MESH] Peer-to-Peer Mesh Geofencing (Offline Consensus)

- **Spec:** `docs/product/NOVA-001-visionary-features.md#3-dynamic-air-gap-isolation--ephemeral-lockdown`
- **Goal:** Sub-50ms eBPF/WFP network cutoff, ephemeral memory vaults, dual-admin cryptographic re-entry keys.
- **Assigned Agent:** Hermes

### 4. [NOVA-001-PQ] Post-Quantum Location Attestation & TPM Proofs
- **Spec:** `docs/product/NOVA-001-visionary-features.md#4-post-quantum-location-attestation--hardware-tpm-sealed-proofs`
